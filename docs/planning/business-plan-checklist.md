# 사업계획서 필수 요소 체크리스트

홍익대 기업과경영 수업자료(34장) 기준. 항목을 채울 때마다 체크한다.

## 1. 필수 내용 8가지

- [ ] 1. 타겟고객 설정
- [ ] 2. 고객문제 정의
- [ ] 3. 고객대안 및 경쟁자 분석
- [ ] 4. 시장조사
- [ ] 5. 솔루션: 가설수립
- [ ] 6. 수익모델
- [ ] 7. 사업화전략
- [ ] 8. 비즈니스모델 캔버스

## 2. 항목별 작성 포인트

### 타겟고객 · 고객문제

- [ ] 고객이 실제로 겪는 불편과 잠재 니즈를 다룸 ("진짜 문제")
- [ ] 디자인씽킹 3질문에 답함
  - Real: 정말 불편한가
  - Inspiring: 진정 해결하고 싶은가
  - Valuable: 해결할 가치가 있는가
- [ ] 도구 활용: 페르소나, 고객여정지도, 이해관계자 지도
- [ ] JTBD: 고객이 해결하려는 일(Job)과 Pain Point 정리

### 솔루션 · 가설수립 (린스타트업)

- [ ] 가설 수립 → MVP → 고객 반응 측정 (Build-Measure-Learn)
- [ ] MVP 유형 선택: 영상 / 컨시어지 / 오즈의 마법사
- [ ] 필요 시 피벗 언급
- [ ] (선택) AARRR 핵심지표, 성장엔진

### 고객대안 · 경쟁자 · 시장조사

프레임워크 중 선택·조합한다. 한계가 있으므로 하나만 쓰기보다 조합한다. (예: PEST·SWOT + STP·4P)

- [ ] PEST: 정치·경제·사회·기술 (거시환경)
- [ ] SWOT: 강점·약점·기회·위협
- [ ] 5 Forces: 공급자·구매자·경쟁자·대체재·신규진입자
- [ ] STP: 세분화·타겟·포지셔닝 (포지셔닝 맵 활용 가능)
- [ ] 3C: 고객·회사·경쟁자
- [ ] 4P: 제품·가격·유통·촉진

### 수익모델

- [ ] 수익원과 비용구조 정리 (캔버스에 포함)

### 사업화전략

- [ ] 채널: 고객 도달·유지 경로
- [ ] 경쟁우위 (Unfair Advantage)
- [ ] 4P·STP로 실행 전술 설계

## 3. 비즈니스모델 캔버스 (3가지 중 택1)

번호는 작성 순서다.

- [ ] **BMC**: 고객군 → 가치제안 → 채널 → 고객관계 → 수익원 → 핵심자원 → 핵심활동 → 핵심파트너 → 비용구조
- [ ] **Lean Canvas**: 문제 → 고객군 → 고유가치제안 → 솔루션 → 채널 → 수익원 → 비용구조 → 핵심지표 → 경쟁우위
- [ ] **사업모델 구조화 지도 (이성준 교수)**: 고객문제 → 고객세분화 → 고객대안 → 솔루션 → 경쟁우위 → 채널 → 고객가치 → 수익구조 → 비용구조

## 4. 참고: 정식 사업계획서 구성 (선택)

- **세쿼이아 체크리스트**: 회사 목적(한 문장), 문제, 솔루션, Why now, 시장 잠재력, 경쟁/대체재, 비즈니스 모델, 팀, 재무, 비전(5년 후)
- **Business Plan 구성**: 회사개요, 사업현황, 시장분석, 제품소개, 재무실적 및 계획, 향후전망
- **IR/Pitch Deck 구성**: 고객문제, 솔루션, 차별화요소, 시장규모, 경쟁사 현황, 성장가능성, 수익구조, 팀

## 5. 작성 팁

- [ ] 논리는 주장(Claim)과 사실(Fact)을 세트로 쓴다. 출처 있는 사실을 제시한다.
- [ ] 설득 구조 WHWE를 따른다: What(문제) / How(해결방안) / Why(이유) / Evidence(증거)

### 슬라이드 규칙

- [ ] 항목은 최대 4개 이하
- [ ] 항목 간 분량과 표현 구조 통일
- [ ] 도형과 기호로 글자 수 줄이기
- [ ] 고딕 계열 폰트, 본문 24~30pt
- [ ] 헤드라인은 신문 기사처럼
