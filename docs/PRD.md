# FanStay PRD (초안 v0.1)

- 작성일: 2026-11-06
- 근거: 사업계획서(FanStay) + 1105 1차 회의록(아이디어 구체화)
- 상태: 초안. 회의에서 방향만 정해진 항목이 많아, 확정 사항과 가정/미정을 구분해 표기함

---

## 1. 한 줄 정의

**콘서트 팬이 "공연 전 휴식 → 공연 → 안전한 귀가"를 한 서비스에서 해결하는 공연 연계 숙소·이동 플랫폼.**

## 2. 배경과 문제

| 문제 | 근거(회의록) |
|---|---|
| 기존 패키지(SM 계열, '놀')는 셔틀 여부에 따라 호텔이 지정돼 숙소 선택권이 좁음 | §1 |
| 한국은 도쿄돔 옆 호텔 같은 접근성이 없어 숙소·대중교통 경로를 직접 찾아야 함 | §1 |
| 심야 귀가가 불안해 보호자가 동반해 오는 경우가 많음 | §6 |
| 네이버·카카오맵은 공연장까지 경로만 제공, 내부 편의시설·짐 보관 정보 없음 | §4, §7 |
| 혼자 오는 팬이 많아 Twitter에서 동행을 구함 (신원·안전 확인 불가) | §3 |
| 외국인 팬은 Google Maps에 의존해 정보를 놓침 | §5 |

## 3. 목표 / 비목표

**목표**
1. 팬이 제휴 숙소 중 선택하고, 공연 후 숙소까지 안전하게 귀가하는 경험을 제공한다.
2. 결제자(보호자)가 "안심"에 지불하는 구조로 가격 민감도를 낮춘다.
3. 티켓 인증으로 "실제 참석자"만 모인 신뢰 기반 커뮤니티를 만든다.

**비목표 (1차)**
- 티켓 대행 판매 (확보 자체가 어려움)
- 가이드 투어 직접 운영, 택시회사 제휴
- 엔터사 제휴 의존 모델

## 4. 타깃 사용자

| 페르소나 | 특징 | 핵심 니즈 |
|---|---|---|
| **팬 (사용자)** | 10~20대 중심, 혼자 오는 경우 많음, 지방/해외 원정 | 공연장 근처 숙소, 심야 이동, 동행 |
| **보호자 (결제자)** | 미성년 팬의 부모 등, 공연 중 대기 | "잘 들어갔는지" 확인, 불안 해소 |
| **외국인 팬** | Google Maps 의존 | 쉬운 이동·정보, 공연 중심 일정 |
| **B2B 파트너** | 숙소, 승합차 전세, 카페 등 | 수요 확보 |

## 5. 기능 우선순위

회의에서 아이디어가 넓게 나왔으므로, **"숙소+귀가"를 코어로 두고 나머지는 단계적으로 붙이는 구조**를 제안함.

| 순위 | 기능 | 단계 | 근거 |
|---|---|---|---|
| **P0** | F1 공연장별 제휴 숙소 선택 (3~4곳) | MVP | 기존 서비스 대비 핵심 차별점 |
| **P0** | F2 티켓 인증·연동 | MVP | 모든 신뢰 기능의 전제 |
| **P0** | F3 안전귀가 (보호자 알림) | MVP | 결제자 ≠ 사용자 구조, 핵심 수익 포인트 |
| **P0** | F4 귀가 이동 수단 (승합차/동승 안내) | MVP | F3 실현 수단 |
| **P0** | F5 공연장 상세 지도 (화장실·식음료·짐 보관) | MVP | 제휴·인력 불필요, 티켓 없이도 이용 가능, 락인 효과 |
| **P0** | F6 보호자 위치 공유 (상호 동의 방식) | MVP | 젠리 등 위치 공유 앱과 같은 방식으로 수용성 확인. 위치정보법 검토 병행 |
| **P0** | F7 티켓 인증 기반 동행 매칭 | MVP | Twitter 동행 수요 해결. 안전·인증 설계 병행 필요 |
| **P2** | F8 생일카페 검색·예약 | v2 | 제휴처 확보 필요 |
| **P2** | F9 굿즈 숙소 배송 / 짐 보관 | v2 | 업체 제휴 필요 |
| **P3** | F10 외국인 AI 투어·덕질 내비 | v3 | 범위 큼, 시장 검증 후 |
| **P3** | F11 익명 데이터 제공 (B2B) | v3 | 법적 요건·구매 의사 미검증 |

## 6. 기능 상세 요구사항

### F1. 제휴 숙소 선택
- 공연장(고척, 올림픽공원·체조경기장 등)별로 제휴 숙소 3~4곳 노출
- 비교 기준: 공연장 거리, 대중교통 접근성, 심야 이동 편의·안전, 가격
- 예약·결제, 취소 정책 안내

### F2. 티켓 인증·연동
- 사용자가 직접 예매한 티켓을 인증하면 숙소 신청·커뮤니티 기능 해금
- **티켓이 없어도** 지도 등 일부 기능은 이용 가능 (늦게 구한 사용자도 숙소 신청 가능)
- 인증 수단: **미정** (예매 내역 캡처/예매번호/예매처 연동 후보)

### F3. 안전귀가 보호자 알림
- 예약 시 팬이 보호자(또는 친구)를 직접 초대. 동의 주체는 본인, 미성년자는 법정대리인 동의
- 자동 알림: 셔틀 탑승 → 숙소 도착 → 입실 완료
- 기본은 알림, 위치 공유는 선택 (F6)
- 마케팅 메시지: "안전 귀가 보증"

### F4. 귀가 이동 수단
- 택시회사 제휴는 현실성이 낮아 제외
- 1안: 9~11인승 승합차 B2B 전세, 같은 권역 숙소 팬 6~8명 조합, 숙소 앞 하차
- 2안: 셔틀마다 안내 인력 1명 동승 (팬덤 이해·외국어 가능), 안전 확인·위치 안내
- 탑승·입실 확인 방식: QR / 기사 단말 / 숙소 연동 중 택1 (미정)

### F5. 공연장 상세 지도
- 화장실, 식음료, 간이 보관소, 주변 접근성
- 개인화: 가입 시 비건·알레르기·이동 조건 입력 → 맞는 식당·시설 추천

### F6. 위치 공유 (상호 동의, MVP)
- 팬과 보호자가 서로 수락해야 연결되는 방식 (젠리 등 위치 공유 앱 참고)
- 귀가 구간에서 팬이 켠 경우만 공유, 입실 완료 시 자동 종료, 팬이 언제든 끌 수 있음
- 미성년자는 법정대리인 동의 추가
- 확인 필요: 위치정보 수집·전달에 따른 위치정보법상 신고 대상 여부

### F7. 동행 매칭 (MVP)
- 티켓 인증 사용자만 참여
- 프로필: 연령대, 공연 선호도. 매칭 모드: 성향 유사 / 상이 / 무작위
- 안전: 본인 인증, 여성 인증, 미성년자 보호자 동행 여부 표시

### F8~F11 (후순위, 요약)
- F8 '플레이스'형 대관 장소 DB (연락처·Instagram·예약 가능 여부·가격·메뉴), 검색~연락~예약 지원
- F9 부스 굿즈 숙소 배송, 지도에 보관소 표시 (현장 업자 의존은 안심 문제)
- F10 입출국 동선 포함 공연 중심 일정 생성, 사용자 제안 장소 + AI 검색, 투표로 선정
- F11 동의 + 익명화한 소비·참여 경향 데이터 판매

## 7. 수익 모델 (가설)

| 수익원 | 설명 | 확실성 |
|---|---|---|
| 숙소 예약 수수료 | 제휴 숙소 중개 | 높음 |
| 안전귀가 옵션 요금 | 보호자 결제, 부가 옵션 | 중간 (지불 의향 검증 필요) |
| 셔틀 이용료 | 승합차 좌석 단위 | 중간 |
| 제휴 광고/예약 수수료 | 생일카페, 보관, 굿즈 배송 | 낮음~중간 |
| 데이터 판매 | 엔터사 대상 | 낮음 (회의에서 "신선하다" 평가, 법적·구매 의사 미검증) |

## 8. 성공 지표 (예시)

- 공연당 숙소 예약 전환율
- 안전귀가 옵션 선택률 / 보호자 초대율
- 티켓 인증 완료율
- 재이용률 (다음 공연 재예약)
- 귀가 완료 알림 성공률, 안전 사고 0건

## 9. 리스크와 미결 사항

| 영역 | 내용 | 대응 방향 |
|---|---|---|
| 법률 | 위치정보, 미성년자 개인정보·동의, 데이터 익명화 요건 | 위치 공유·데이터 판매는 법률 검토 후 |
| 운영 | 동승 인력·승합차 확보, 비용 | 소규모 시범 운영 후 확장 |
| 수요 검증 | 보호자 추가 요금 의향, 팬의 위치 공유 부담 | 설문·인터뷰 |
| 인증 | 티켓 인증 수단 미설계 | 가장 먼저 결정 |
| 제휴 | 숙소·카페·보관 업체 확보 | 공연장 1~2곳 집중 |
| 안전 | 동행 매칭 중 오프라인 사고 | 인증·신고 체계 선행, 후순위 |

## 10. 단계별 로드맵 (제안)

| 단계 | 범위 |
|---|---|
| **MVP** | 고척 또는 올림픽공원 1곳 한정. 숙소 선택 + 티켓 인증 + 보호자 알림·위치 공유 + 승합차 귀가 + 공연장 상세 지도 + 동행 매칭 |
| v1.1 | 지도 개인화(비건·알레르기) |
| v2 | 생일카페, 굿즈 배송·보관 |
| v3 | 외국인 AI 투어, 데이터 B2B |

## 11. 팀 내 결정이 필요한 사항

1. MVP 공연장을 어디로 할지 (고척 / 올림픽공원)
2. 티켓 인증 방식
3. 귀가 수단을 승합차 전세 vs 동승 가이드 중 무엇으로 시작할지
4. 데이터 수익화를 사업계획서 수익 모델에 포함할지
5. 외국인 대상을 초기에 포함할지, 후순위로 둘지
