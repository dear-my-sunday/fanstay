# FanStay

콘서트 팬이 "공연 전 휴식 → 공연 → 안전한 귀가"를 한 서비스에서 해결하는 공연 연계 숙소·이동 플랫폼. (기업과 경영 기말 팀프로젝트)

## 구성

| 경로 | 내용 |
|---|---|
| [docs/PRD.md](docs/PRD.md) | PRD 초안 (1105 1차 회의록 기반) |
| [docs/IA.md](docs/IA.md) | 정보구조(IA). 원본은 FigJam |
| [wireframes/index.html](wireframes/index.html) | 로파이 와이어프레임 초안 (브라우저로 열기) |

## 이어서 작업하기

```bash
git clone https://github.com/dear-my-sunday/fanstay.git
cd fanstay
open wireframes/index.html   # macOS
```

## 현재 상태

- MVP 범위: 숙소 선택, 티켓 인증, 보호자 알림·위치 공유, 승합차 귀가, 공연장 지도, 동행 매칭
- 와이어프레임은 핵심 7개 화면만 있는 초안이며, 문구와 데이터는 모두 예시임
